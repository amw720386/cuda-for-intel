# Decode on stock Ollama: Arc B390 and Arc 140V, 2026-11-11

Numbers behind PRs #42, #43 and #45 and the README speed note. They were transcribed from the benchmark sessions on the two
boxes (`scripts/bench-decode.ps1` JSON and the test-binary console output). The raw files stay on the boxes. All runs use stock
Ollama v0.12.6 on the shim and Qwen2.5-0.5B-Instruct Q8_0 (`ca59ca7f…`) with the bench-decode request shape: 631-token prompt,
48 greedy tokens, `num_ctx` 2048, every measured prompt new to the KV cache.

Every Ollama cell logged `library=CUDA` and 25/25 layers on the GPU. The 48-token counting-prompt text equals the CPU backend
in every cell. With flash attention on and the fast mmvq (#42), the free-text story prompt diverges from the CPU backend at
character 108; the text stays coherent. The cause is float add order, as noted in #18.

## Arc B390 (Xe3, Core Ultra X7 358H, driver 32.0.101.9033)

| build | FA | prefill p50 | decode p50 (best) | per-server decode p50 | Vulkan / ours |

| main 6f165a5 | off | 7006 | 38.9 (40.8) | 37.9 / 38.9 / 39.6 | 4.05x |

| #42 + #43 | off | 7215 | 57.8 (60.5) | 57.7 / 59.3 / 57.2 | 2.72x |

| #42 + #43 | on | 8075 | 58.9 (61.7) | 60.0 / 59.1 / 58.8 | 2.65x |

The Vulkan reference is 157.4 tok/s decode with FA off and 156.2 with FA on ([vulkan-baseline-2026-11-10.md](vulkan-baseline-2026-11-10.md)).
Its prefill p50 is 7188 (FA off) and 8030 (FA on), so prefill is at parity.

With `CUDA_FOR_INTEL_MAX_INFLIGHT_GROUPS=0` on top of #42 + #43, decode rose 3-5 % with FA off, but FA-on prefill fell to about
2150. That setting is not adopted.

and 0.66 µs per kernel when replayed from a recorded command list.

## Arc 140V (Xe2, Core Ultra 7 268V, driver 32.0.101.9175)

One fresh server per cell, 5 runs.

| build | FA off decode p50 (best) | FA on decode p50 (best) |
|---|---|---|
| main 6f165a5 | 23.1 (23.9) | 27.2 (27.6) |
| #42 7318dee | 39.8 (40.4) | 46.8 (48.6) |
| #42 + #43 (launch-host-path 52b53d1) | 39.7 (41.9) | 47.2 (52.3) |

Stock Ollama 0.40.14 Vulkan on the same box decoded at 111.5 / 127.8 tok/s (FA off / on), with text equal to the CPU backend.
A Rust build overlapped that run, so the Vulkan numbers may be slightly low. Ollama 0.40.14 runs on the CPU unless
`OLLAMA_IGPU_ENABLE=1` is set.

The 140V's Intel driver 32.0.101.5564 did not load: Code Integrity event 3004, because the WHQL catalog certificate expired.
Driver 32.0.101.9175 from intel.com, Authenticode-valid, fixed it.
